**Function:**

This script was created to make a PDF gird of a selection of images.



**Goal**
This program was written to automate the process of compiling representative TEM images into a single PDF.





**Initial Setup:**

\-The images of interest (4-8: valid image types ('.png', '.jpg', '.jpeg', '.tiff', '.tif', '.TIFF')) are read from a shared folder and compiled into a grid in alphanumeric order left to right row by row or top to bottom column by column.

\-There is a magnification scale dict so that magnifications can be converted to scale bar labels



**Running the program:**

\-There is no menu currently. This program cannot be run as a .exe in its current state.

\-The user manually fills in the file path, the title, sample names and magnification groupings, and which way the images are drawn to the screen prior to running the script.





**Things to remember:**

**-------------------**

\-Having any of the needed files open will cause the program to crash. Rerunning the program with the file closed will fix that issue.

\-Additional runs will overwrite the previous image compiled PDF.
